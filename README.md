# 📝 Notes App (MERN Stack)

Полнофункциональное приложение заметок с авторизацией и удобным интерфейсом. Построено на стеке **MERN**: MongoDB, Express.js, React.js, Node.js.

## 🚀 Функциональность

- 🔐 Аутентификация: регистрация и вход
- ➕ Добавление и ✏️ редактирование заметок
- 📌 Закрепление важных заметок вверху
- 🔍 Поиск по заметкам
- 🗑️ Удаление заметок
- 🎨 Tailwind CSS UI

## 📦 Технологии

- **Frontend**: React, Tailwind CSS, React Router, Axios
- **Backend**: Node.js, Express.js, MongoDB, Mongoose, JWT
